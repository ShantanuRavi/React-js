Virtual DOM in React (Simple Explanation):-

1) Virtual DOM is a lightweight copy of the real DOM that React keeps in memory.
2) DOM (Document Object Model) represents the actual HTML page in the browser.
3) When something changes in a React app (for example, state changes), React updates the Virtual DOM first, not the real DOM.
4) React compares the new Virtual DOM with the previous Virtual DOM. This process is called diffing.
5) React finds only the parts that have changed.
6) React then updates only those changed parts in the real DOM. This process is called reconciliation.
7) Updating only the required parts makes React applications faster and more efficient.



createRoot() in React (Simple Explanation):-

1) createRoot() is a React function used to create a connection between React and an HTML element in the browser.
2) It tells React where to display the React application inside the real DOM.
3) It is imported from react-dom/client:-

    import { createRoot } from "react-dom/client";

4) Example:-

    const root = createRoot(document.getElementById("root"));
    root.render(<App />);

5) How it works:-

    1) In HTML, we usually have a container:
        
      <div id="root"></div>

    2)  createRoot() selects this div and creates a React root.
    3)  render() tells React what component should be displayed inside that root.
    4)  React then creates a Virtual DOM representation of your components.
    5)  React compares the Virtual DOM with the previous Virtual DOM whenever changes happen.
    6)  React updates only the required parts of the real DOM inside the root element.

-----------------------------------------------------------------------------------------------------

HTML DOM
   |
   |  createRoot()
   ↓
React Root
   |
   |  render(<App />)
   ↓
Virtual DOM
   |
   |  Compare changes (Diffing)
   ↓
Real DOM Update

------------------------------------------------------------------------------------------------------

Simple analogy:

1) createRoot() = creates a playground where React controls the UI
2) Virtual DOM = React's plan/blueprint of the UI
3) Real DOM = actual webpage shown in the browser

So, createRoot() does not create the Virtual DOM itself.
It creates the entry point where React manages the Virtual DOM and
updates the real DOM efficiently.
